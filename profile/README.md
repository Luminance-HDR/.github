## What Is Luminance HDR

Luminance HDR is a study-friendly merge helper for brackets you shot yourself. Luminance HDR bracket merge builds the wide-range image. Luminance HDR tone operator then chooses how that range is drawn: a gentler operator for a home interior, or a stronger one when you are comparing methods for class. The value is being able to see more than one result from the same frames.

Luminance HDR exposure fusion is the other route. It mixes the original exposures directly, which often looks calmer for a small print. Luminance HDR ghost mask belongs to either route when something in the scene moved. Luminance HDR hdr preview lets you reject a harsh operator before you wait on a large save. That preview is the right place to decide, especially on a laptop used for homework.

Keep a notebook of which Luminance HDR tone operator you liked. Run Luminance HDR bracket merge once, compare it with Luminance HDR exposure fusion, and use Luminance HDR ghost mask only on the moving part. Trust Luminance HDR hdr preview at a size large enough to see halos. Save the version that still looks like the room.
